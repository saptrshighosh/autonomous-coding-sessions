autonomous-coding-sessions 0.1.0 is the first release: a community-written playbook for running Claude Code with little supervision, compiled from one public conference talk. It is unofficial.

### What is in it

- **Four skills:** `autonomous-coding-sessions` (core playbook with eight reference files and templates), `autonomy-audit`, `reversibility-check`, `verification-plan`.
- **Two agents:** `autonomy-auditor` and `fresh-context-reviewer`, both read-only.
- **One command:** `/stuck-points`.
- **Example tooling:** a read-only audit script, three opt-in hook scripts, a hardened example project, `install.sh`, and a reproducible packaged skill archive.
- **Trust material:** `docs/HONEST-LIMITS.md`, `docs/PROVENANCE.md`, committed checksums, and a verifier that fails if a figure in a skill is not recorded in provenance.

### Read before you rely on it

- No skill has been evaluated for effect. `evals/` holds cases and graders only; no results are published.
- The example hooks have not been run in a live Claude Code session, and the GitHub Actions workflows have not run on GitHub.
- Hook event names and exit-code semantics came from a third-party guide, and the claim that a `Read` deny rule also stops `cat` is the talk's. Verify both on your version.
- Windows is unsupported.

See `docs/HONEST-LIMITS.md` for the full list.
